PROJECT OVERVIEW

Your Mozosubz WhatsApp AI Bot is fully built and ready for deployment!

WHAT EACH COMPONENT DOES
════════════════════════════════════════════════════════════════════════

server.js
  Main Express server that:
  - Initializes database and bot
  - Provides health check endpoints
  - Handles graceful shutdown
  - Logs all requests

database.js
  PostgreSQL connection that:
  - Creates users, conversations, api_calls_log tables
  - Manages database queries
  - Handles connection pooling

bot.js
  WhatsApp integration that:
  - Listens for incoming messages
  - Loads conversation history
  - Sends messages to AI
  - Executes API calls
  - Returns responses to WhatsApp

aiClient.js
  Open Router AI integration that:
  - Sends user message + history + system prompt to AI
  - Parses AI response for API calls
  - Extracts user-friendly message
  - Handles rate limiting

systemPrompt.js
  Comprehensive AI instructions with:
  - Full Mozosubz API documentation embedded
  - Service descriptions (data, cable, electricity, etc.)
  - Output format specifications
  - Rules for conversation flow

mozosubzClient.js
  Mozosubz API wrapper that:
  - Authenticates users via WhatsApp phone
  - Fetches data/cable/electricity plans
  - Executes purchases
  - Checks balance
  - Processes deposits

conversationService.js
  Database service that:
  - Manages user profiles
  - Stores conversation history
  - Logs API calls for auditing
  - Retrieves context for AI


QUICK START GUIDE
════════════════════════════════════════════════════════════════════════

1. Install Dependencies
   cd bot
   npm install

2. Configure Environment
   cp .env.example .env
   nano .env
   
   Add your:
   - OPENROUTER_API_KEY (from https://openrouter.ai)
   - DATABASE_URL (PostgreSQL connection)

3. Start the Bot
   npm run bot:start
   
   First run will show QR code - scan with WhatsApp

4. Test
   Send a message: "What's my balance?"

5. Deploy to Render
   See DEPLOYMENT.md for step-by-step guide

HOW IT WORKS IN PLAIN ENGLISH
════════════════════════════════════════════════════════════════════════

1. User sends WhatsApp message: "Buy me 1GB of MTN data"

2. Bot receives message via WhatsApp Web.js

3. Bot loads previous conversation (for context)

4. Bot sends to Open Router AI with:
   - Full Mozosubz API documentation
   - User message
   - Previous messages (context)
   - Instructions on what to do

5. AI interprets: "User wants MTN data"

6. AI generates API call: GET /api/whatsapp/data/plans

7. Bot executes call, gets plans

8. AI asks user which amount they want (or includes in response)

9. User: "250 naira"

10. AI generates: POST /api/whatsapp/data/purchase

11. Bot executes purchase

12. AI writes user-friendly response: "✅ You bought 1GB MTN data for ₦250"

13. Bot sends response back to WhatsApp

14. Everything is saved to database

TROUBLESHOOTING CHECKLIST
════════════════════════════════════════════════════════════════════════

Issue: Bot won't start
  □ Check Node.js is installed (v18+)
  □ Check all env variables are set
  □ Check PostgreSQL is running
  □ Check DATABASE_URL is correct

Issue: QR code not showing
  □ Try different terminal
  □ Make sure you're running on your machine (not SSH)

Issue: Database connection failed
  □ Verify PostgreSQL is running
  □ Check DATABASE_URL format
  □ Test connection: psql $DATABASE_URL

Issue: API errors
  □ Check OPENROUTER_API_KEY is valid
  □ Check MOZOSUBZ_API_BASE URL
  □ Check network connectivity

Issue: Bot not responding
  □ Check logs: npm run bot:dev
  □ Verify WhatsApp is authenticated
  □ Check if PostgreSQL has space
